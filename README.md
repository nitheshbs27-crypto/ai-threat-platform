# AI Threat Intelligence Platform

An AI-powered cybersecurity platform that detects, analyzes, scores, and explains cyber threats using machine learning, FastAPI, React, MongoDB, and a security chatbot.

## Features

- Secure login API
- Threat dashboard
- AI anomaly detection
- AI phishing URL detection
- Threat scoring engine
- MongoDB threat storage
- Live alert simulation
- AI security chatbot
- Dark cybersecurity UI
- Threat analytics graph

## Tech Stack

- React.js
- FastAPI
- Python
- MongoDB
- Scikit-learn
- Chart.js
- Axios
